Webhooks & multi-domain

Webhooks

Webhooks POST a JSON payload to your endpoint when events happen:

EventFires when
url.createda short URL is created (payload: the short URL object)
visit.recordeda short URL is visited
orphan_visit.recordedorphan traffic is recorded

Delivery format:

POST <your-url>
X-Shortlink-Event: visit.recorded
X-Shortlink-Signature: sha256=<hex>

{
  "event": "visit.recorded",
  "occurredAt": "2026-08-19T10:32:16Z",
  "data": { "visitType": "valid", "shortUrl": { "shortCode": "promo", … }, … }
}

The signature is the HMAC-SHA256 of the raw request body using the webhook's secret (shown once at creation). Verify it before trusting a delivery:

# python
import hmac, hashlib
expected = "sha256=" + hmac.new(secret.encode(), body, hashlib.sha256).hexdigest()
valid = hmac.compare_digest(expected, request.headers["X-Shortlink-Signature"])

Failed deliveries are retried with exponential backoff (up to 6 attempts) from a persistent queue that survives restarts. Webhooks can be disabled temporarily without losing their configuration.

Multi-domain

One instance can serve short URLs on many domains. Short codes are unique per domain, so sho.rt/hi and go.example.com/hi can point at different targets.

  1. Point the extra domain's DNS at your instance (and terminate TLS at your proxy).
  2. Register it under Domains — or simply create a short URL with that domain and it registers itself.
  3. Optionally give the domain its own not-found redirects (base URL, regular 404, invalid short URL); these override the global settings.

The domain the visitor used is matched by the request's Host header; unknown hosts fall back to the default domain. The default domain (from SHORTLINK_DEFAULT_DOMAIN) cannot be deleted.

Not-found behavior

Three kinds of miss, each with its own configurable redirect (global via environment variables, or per domain):

CaseSetting
Visit to the bare domainSHORTLINK_BASE_URL_REDIRECT
Unknown or expired short codeSHORTLINK_INVALID_SHORT_URL_REDIRECT
Any other 404SHORTLINK_REGULAR_404_REDIRECT

Unset targets render a minimal landing/404 page instead.
