Shortlink

A self-hosted URL shortener with a full REST API, an htmx-powered admin dashboard and privacy-aware visit analytics. Written in F# on Falco, runs as a single binary with SQLite or PostgreSQL.

Highlights

  • Short URLs — generated codes or custom slugs, tags, titles, configurable redirect status, query-string forwarding.
  • Conditional redirect rules — send Android, iOS, language, query-param or IP-range traffic to different targets per link.
  • Lifetime controls — start/end dates and maximum visit counts.
  • Analytics — referrers, browsers, operating systems, devices, bot detection and GeoLite2 geolocation, with orphan-traffic tracking. IPs are anonymized by default.
  • Multi-domain — serve many domains from one instance; codes are unique per domain.
  • REST API — everything scriptable, with role-scoped API keys.
  • Webhooks — signed JSON deliveries with retries.
  • QR codes — PNG or SVG for every link.
